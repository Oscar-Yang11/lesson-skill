# 页面组件怎么写

样式都在 `assets/template.html` 的 `<style>` 里，复制模板后直接用下面这些类名。

## 开头框
```html
<div class="goal">
  <p class="q">这一课回答的问题：……？</p>
  <p>读完你能：</p>
  <ul><li>……</li></ul>
  <p class="meta">约 10 分钟　·　需要先知道：……</p>
</div>
```
“读完你能”写成读者能做的事（“对着一帧画面自己算出答案”），不要写成“了解……”。

## 一节
```html
<h2 id="s2"><span class="n">2</span>这一节要回答的问题？</h2>
<p>第一句接住上一节留下的问题……</p>
...
<div class="recap"><b>到这里</b>　我们知道了……</div>
<p class="next">可是……？</p>
```
左侧进度条里对应加一行 `<a href="#s2">2　短一点的问题</a>`。

## 图
```html
<figure class="fig"><img src="fig/x.jpg" alt=""><figcaption><b>图 2</b>　从图上能看出什么。</figcaption></figure>
```
- 连续几帧画面用 `<div class="strip" style="grid-template-columns:repeat(5,1fr)">`，每格一张图加下面的说明。
- 曲线、条形图、示意图用内联 SVG 或脚本生成的 SVG 文件。SVG 里的字号按最终显示宽度约 720 px 来定，不小于 12 px。
- 图里要让读者看的地方，用箭头或色块加一两个字直接标在图上。

## 为什么 / 想一想 / 想看细节
```html
<div class="why"><b>为什么这样做</b>　不这样做会怎样……</div>
<details class="think"><summary>想一想：……？</summary><p>答案……</p></details>
<details class="more"><summary>想看细节：……</summary>……</details>
```
“想一想”的问题要让读者用刚讲的东西就能答出来；不要问还没讲的。

## 出处标记
```html
……约 1 秒<a class="src m" href="#src3">实测 3</a>
```
类名：`m` 实测，`u` 你定的，`j` 我的判断，`p` 文献，`c` 代码。数字对应文末出处表的行（`<tr id="src3">`）。同一个出处重复出现时用同一个数字。

## 三选一这类离散答案
```html
<span class="chip on">右</span><span class="chip">不动</span>
```
`on` 表示要动，默认灰色表示“不动”，`go` 用来强调“做这个动作”（例如手指“合”）。

## 目录页（多课时）
每一课一行：第几课、它回答的问题、需要先读哪一课、写好了没有。没写的课也列出来，读者能看到整门课的全貌。

## 要让读者横着比的东西，必须对齐
同一组答案在几个时刻的变化、几种做法的对比：做成一张对齐的网格（每行一个量，每列一个时刻），不要让小牌子自己换行。换行以后各列的行数不一样，读者就看不出“这一项从左到右怎么变”。

## 同一张图，一节加一层
同一条曲线或同一幅画面要在连续几节里用到时，不要每节换一张新图。保留同样的坐标和画法，每节只多画一层（先是曲线和折返点，再加子片段的边界，再标出取用的帧）。读者不用重新认图，注意力都在新加的那一层上。

## 对比两种做法：只让不同的那一格显眼
把两种做法的结果放进同一张对齐的表，相同的格子用同样的样子，只把不同的格子框出来。读者一眼看到“差别就在这里”，比两张并排的图有效。
